# NoDupe releases

This repository holds no source code. It publishes the signed release list of NoDupe (`NoDupe/index.json`) and, as GitHub releases, the installers named `NoDupe-v<version>`.

Every release is signed by Technowiz Solutions, and NoDupe checks that signature itself before it installs anything.

Downloads and what changed in each version: https://technowizsolutions.com

Windows may warn before it runs an installer that is not yet signed by a trusted publisher. The [install guide (PDF)](NoDupe/NoDupe-Install-Guide.pdf) shows each screen and what to click. It is attached to every release and is inside the zip next to the installer.
